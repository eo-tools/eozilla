# Eozilla Cuiman

The _Cuiman_ tool provides a client for servers compliant with the 
[OGC API - Processes, Part 1](https://github.com/opengeospatial/ogcapi-processes).

It comprises the following interfaces:

- [Python API guide](../docs/cuiman/guides/api.md)
- [Eozilla App guide](../docs/cuiman/guides/app.md), for browser and notebook use
- [Command-line guide](../docs/cuiman/guides/cli.md)

Use the [opener guide](../docs/cuiman/guides/openers.md) to read an original output
or selected resource, and the [resolver guide](../docs/cuiman/guides/resolvers.md)
to discover STAC Assets and configured folder descendants. The
[job result resources notebook](../notebooks/cuiman-job-result-resources.ipynb)
provides a current, runnable walkthrough using the local testing service.
